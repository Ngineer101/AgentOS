Self-hosted · open source

Run your coding agents on your own machine. Steer them from anywhere.

AgentOS is a host for Claude Code, Codex, OpenCode, Cursor and Antigravity that runs on your Linux or macOS computer, on the subscriptions you already have. Every session is sandboxed. You drive it from a desktop app, the command line or your iPhone, and your code never leaves your machine.

One daemon on your computer. Nothing else in the middle.

The host starts each agent CLI as shipped, inside its own sandbox, and keeps every session in a local log. Your phone reaches it through a relay you deploy yourself, which only ever carries ciphertext.

The host listens on no network port. It dials out to the relay, which forwards end-to-end encrypted frames it cannot read.

The sandbox is the boundary

Agents run with their own approvals on auto. What keeps them in check is what the sandbox lets them reach, not a prompt before every command.

Sandboxed sessions

Each session runs in bubblewrap and seccomp on Linux or Seatbelt on macOS. It can write only its workspace and its own state, and can't read your secrets or other agents' logins.

Network allow-list

A session reaches the network only through its own proxy, which allows the agent's provider plus the hosts you choose for that workspace. Private addresses are refused.

Your credentials stay yours

Pushing, opening pull requests, installing tools and MCP connectors go through the host. It shows you exactly what will run and waits for you to approve.

Your subscriptions, as shipped

The host never runs its own agent loop. Each CLI is driven over the Agent Client Protocol with your existing login, so there is no extra API bill.

End-to-end encrypted

Phones pair by QR code and talk to the host over Noise tunnels. The relay in between has no accounts and stores no transcripts.

Nothing lost on disconnect

Sessions are an append-only event log in SQLite on your machine. Close the laptop lid on the train; the phone catches up without gaps.

Away from your desk, still in the loop

When an agent wants to do something with your credentials, the request comes to you, wherever you are.

Set it up

You build it from source. The host and desktop app take one script; remote access and the iPhone app are optional extras.

  1. Install the host

    You need Rust 1.85+, Node 22+ and the agent CLIs you want, installed and logged in. On Linux also bubblewrap, socat and ripgrep.

    $ git clone https://github.com/Ngineer101/relay.git agentos && cd agentos
$ scripts/install.sh    # builds and installs the host, the CLI and the desktop app
$ agenthost status    # sandbox health, agents, login state

  2. Start your first session

    Add a folder as a workspace and give an agent something to do. Or open AgentOS from your applications and press ⌘N or Ctrl+N.

    $ agenthost workspace add ~/code/myproject --profile packages
$ agenthost run ~/code/myproject claude "Summarise this repo"
$ agenthost chat ~/code/myproject codex    # interactive

  3. Add remote access optional

    Deploy the relay to your own Cloudflare account (the Workers Free plan is enough), point the host at it and pair a device.

    $ cd relay && npm ci && npx wrangler login && npx wrangler deploy
$ cd .. && scripts/install.sh --relay wss://agenthost-relay.<your-subdomain>.workers.dev
$ agenthost device pair    # shows a QR code

  4. Build the iPhone app optional

    There is no App Store build. You build it yourself on a Mac with Xcode, XcodeGen and rustup, then scan the QR code from step 3.

    $ cd ios && ./build-rust.sh && xcodegen generate
$ open AgentHost.xcodeproj

The commands keep the project's earlier name, agenthost. Getting started has the full walkthrough.
