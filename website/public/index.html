The sandbox is the boundary

Agents run with their own approvals on auto. What keeps them in check is what the sandbox lets them reach, not a prompt before every command.

  • Sandboxed sessions

    Bubblewrap and seccomp on Linux, Seatbelt on macOS. A session writes only its workspace and can't read your secrets or other agents' logins.

  • Network allow-list

    Each session reaches only its agent's provider and the hosts you allow for that workspace. Private addresses are refused.

  • Your credentials stay yours

    Pushing, pull requests, installing tools and MCP connectors go through the host, which shows you what will run and waits for your approval.

  • Your subscriptions, as shipped

    No agent loop of its own. Each CLI runs unmodified with your existing login, so there is no extra API bill.

  • End-to-end encrypted

    Phones pair by QR code and talk to the host over Noise tunnels. The relay has no accounts and stores no transcripts.

  • Nothing lost on disconnect

    Sessions are an append-only log on your machine. Lose signal on the train and the phone catches up without gaps.

Away from your desk, still in the loop

Set it up

You build it from source. The host and desktop app take one script; remote access and the iPhone app are optional.

  1. Install the host

    You need Rust 1.85+, Node 22+ and the agent CLIs you want, installed and logged in. On Linux also bubblewrap, socat and ripgrep.

    $ git clone https://github.com/Ngineer101/AgentOS.git && cd AgentOS
$ scripts/install.sh    # builds and installs the host, the CLI and the desktop app
$ agenthost status    # sandbox health, agents, login state

  2. Start your first session

    Add a folder as a workspace and give an agent something to do. Or open AgentOS from your applications and press ⌘N or Ctrl+N.

    $ agenthost workspace add ~/code/myproject --profile packages
$ agenthost run ~/code/myproject claude "Summarise this repo"
$ agenthost chat ~/code/myproject codex    # interactive

  3. Add remote access optional

    Deploy the relay to your own Cloudflare account (the Workers Free plan is enough), point the host at it and pair a device.

    $ cd relay && npm ci && npx wrangler login && npx wrangler deploy
$ cd .. && scripts/install.sh --relay wss://agenthost-relay.<your-subdomain>.workers.dev
$ agenthost device pair    # shows a QR code

  4. Build the iPhone app optional

    There is no App Store build. You build it yourself on a Mac with Xcode, XcodeGen and rustup, then scan the QR code from step 3.

    $ cd ios && ./build-rust.sh && xcodegen generate
$ open AgentHost.xcodeproj

The commands keep the project's earlier name, agenthost.
