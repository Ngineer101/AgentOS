Getting started

Install the host, the CLI and the desktop app on a Linux or macOS computer, then run your first session.

The commands and folders keep the project's earlier name: the CLI is agenthost, the host daemon is agenthostd, and settings start with AGENTHOST_.

Prerequisites

  • Rust 1.85 or newer, and Node 22 or newer.
  • The agent CLIs you want to use (Claude Code, Codex, OpenCode, Cursor), installed and logged in. AgentOS uses your existing logins and subscriptions.
  • On Linux: bubblewrap, socat and ripgrep.

On Ubuntu 24.04, unprivileged user namespaces must be allowed for bubblewrap:

$ sudo sysctl kernel.apparmor_restrict_unprivileged_userns=0

Install

$ git clone https://github.com/Ngineer101/AgentOS.git && cd AgentOS
$ scripts/install.sh    # build and install the host, the CLI and the desktop app
$ agenthost status    # sandbox health, agents, login state

scripts/install.sh does three things:

  • puts agenthostd and agenthost in ~/.local/bin, and installs the desktop app (~/Applications/AgentOS.app on macOS, a launcher entry on Linux);
  • downloads the pinned agent adapters and the sandbox runtime;
  • starts the host at login, as a systemd user service on Linux or a launch agent on macOS.

If ~/.local/bin is not on your PATH, add it to use the CLI.

Antigravity

Antigravity is a standalone binary, not one of the pinned tools. Install it yourself, then sign in once with the command agenthost status shows.

$ curl -fsSL https://antigravity.google/cli/install.sh | bash

Your first session

A workspace is a folder agents may work in. Add one, then run an agent in it:

$ agenthost workspace add ~/code/myproject --profile packages
$ agenthost run ~/code/myproject claude "Summarise this repo"
$ agenthost chat ~/code/myproject codex    # interactive

Or open the desktop app and press ⌘N (Ctrl+N on Linux). Everything the CLI does, the desktop app does too.

No project in mind? The built-in Quick tasks workspace gives each session a fresh, empty folder:

$ agenthost run quick claude "What changed in the latest Rust release?"

Update, restart, uninstall

$ git pull && scripts/install.sh    # rebuild, replace the binaries, restart the host
$ scripts/install.sh --restart    # restart the host service only
$ scripts/install.sh --desktop-only    # just the app, for a laptop that pairs with your host
$ scripts/install.sh --uninstall    # remove the service, binaries and app; keeps your data

Restarting the host stops running agent sessions. They resume where they can.

Try it without installing

scripts/dev.sh builds and runs the host and the desktop app together. Closing the window stops the host.

$ scripts/dev.sh    # your normal data: workspaces and logins carry over
$ scripts/dev.sh --fresh    # a throwaway host with an empty database

Where things live

WhatLinuxmacOS
Data (sessions, workspaces, pairings, tools)~/.local/share/agenthost~/Library/Application Support/agenthost
Host log<data folder>/logs/host.log
Serviceagenthost.service (systemd user)dev.agenthost.host (launch agent)

Something not working? Start with agenthost status, then the host log. To log the raw traffic between the host and an agent:

$ AGENTHOST_ACP_TRACE=1 agenthostd run
